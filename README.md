# 🧠 NeuroLearn AI — Adaptive Learning Studio

> **Learn Anything. Retain Everything.**  
> An AI-powered, multi-modal adaptive learning studio that transforms complex topics into interactive explanations, visual knowledge maps, Feynman technique feedback, adaptive quizzes, and structured study roadmaps.

---

## ✨ Features

NeuroLearn AI equips learners with **5 specialized AI learning tools**:

1. 💡 **Concept Explainer** — Explains any topic in 5 distinct learning styles:
   - **ELI5**: Simple words and relatable analogies.
   - **Scholar**: Academic structure with conceptual depth.
   - **Technical**: Precise definitions and implementation mechanics.
   - **Storytelling**: Engaging narratives with relatable scenarios.
   - **Analogy-Based**: Connects abstract concepts to familiar everyday objects.

2. 🕸️ **Interactive Knowledge Graph** — Generates live, force-directed concept maps powered by **D3.js**.
   - Visualizes core concepts, prerequisites, and related topics.
   - Supports drag-and-drop node exploration, zoom, and interactive connection inspection.

3. 🧑‍🏫 **Feynman Coach** — Evaluates user explanations against a strict scoring rubric (0–100%).
   - Identifies knowledge gaps and provides personalized study recommendations.
   - Features animated visual score gauge and feedback summary.

4. 🎯 **Adaptive Quiz Studio** — Generates 5 multiple-choice questions tailored to the selected topic and difficulty level (Easy, Medium, Hard).
   - Auto-grading engine supporting varied answer formats.
   - Tracks streak, accuracy, and outputs a final Mastery Performance Card.

5. 🗺️ **Adaptive Study Roadmap** — Designs structured curriculums tailored to target timeframes (e.g. 3 days, 1 week, 2 months).
   - Generates daily/weekly milestones, estimated commitment hours, and recommended free resources.
   - One-click text download for offline study tracking.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism & Dark Cyber Aesthetics)
- **Logic**: Vanilla JavaScript (ES6+, Strict Mode)
- **Visualization**: D3.js v7 (Force Simulation & Zoom Behavior)
- **Markdown Rendering**: Marked.js
- **AI Integration**: OpenRouter API (`openrouter/auto` live model routing)

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/neurolearn-ai.git
   cd neurolearn-ai
   ```

2. **Run locally**:
   - Open `index.html` directly in any standard web browser (Chrome, Edge, Firefox, Safari).
   - No server installation or `npm install` required!

3. **API Key Setup**:
   - Click the **OpenRouter Connected** pill in the top-right corner.
   - Enter your [OpenRouter API Key](https://openrouter.ai/keys) to enable live AI responses across all 5 tools.
